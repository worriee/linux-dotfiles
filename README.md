# linux-dotfiles
> this repo does automated backups like it takes snapshots every current state of my os. :>

- `cosmic/` — COSMIC DE on openSUSE Tumbleweed.
- `gnome/` — GNOME on openSUSE Tumbleweed.
- `xfce/` — XFCE on Mint/Ubuntu (apt) or openSUSE TW (zypper). XFCE-only.
- `sway/` — **ARCHIVED.** Config backup from a removed session.
- `common/` — assets and config shared by all three desktops.
